# Local extensions of th-quiz

This file belongs to the project: `copier update` never changes it. Instructions written here
extend the th-quiz skill, and win where they conflict with it.

The quiz policy sets when th-study and th-next offer the quiz before pre-registration. Without a
policy line, they offer it and run it only if the human accepts. To set one, write one of the lines
below outside the comment.
